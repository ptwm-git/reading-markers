# Reading Markers 1.2.0

This release adds a compact navigation control for moving between saved reading positions.

## Highlights

- Use the vertical side control in Markdown Reading view or PDF view.
- Jump upward or downward to the nearest reading marker.
- Return to the center marker after temporarily browsing another part of the document. The first marker initializes the center, while later markers remain separate navigation targets.
- Receive a clear prompt when the center button is used before a marker exists.
- Drag the panel to move it, snap it to either reading-pane edge, or collapse it to the edge.
- Let the panel auto-collapse after four seconds of inactivity and expand it from the edge handle.

The center position belongs to the current Obsidian session. Reading marker data remains unchanged: Markdown markers stay in the note as plugin-owned block IDs, and PDF markers stay in the plugin data without modifying the original PDF.

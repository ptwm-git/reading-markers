# Reading Markers 1.0.0

The first public release of Reading Markers provides persistent, color-coded reading positions for desktop Obsidian.

## Highlights

- Add markers from editing view or Reading view.
- Choose from six colors and scan markers by color below the note title.
- Jump to marked paragraphs, headings, and list items.
- Change colors or remove markers without deleting note content.
- Keep markers attached to content when earlier lines change or notes are renamed.
- Follow the Obsidian interface language in English or Chinese, with English as the fallback.

## Reliability

- Unsupported Markdown structures are rejected with a clear notice.
- Settings are validated and recover safely from malformed data.
- File-operation failures are logged with an action name and shown to the user.
- Continuous typing uses a deferred marker-bar refresh to avoid repeated full scans.

Reading Markers works locally without network access, telemetry, accounts, or files outside the Vault.

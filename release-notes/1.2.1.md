# Reading Markers 1.2.1

This patch release improves navigation across Markdown editing, Reading, and PDF views.

## Fixes

- Keep the Reading view marker bar ready to refresh after a marker is added from the editor.
- Show the vertical navigation panel in both Markdown source view and Reading view.
- Use the editor cursor as the current position while editing.
- Keep the center target separate from the nearest previous and next targets.
- Ask before saving the current reading position when jumping with the up or down control.
- Let the middle control return to the saved temporary position, replacing it on the next confirmed jump.

The temporary return position is session-only and does not create a permanent marker. If it is not saved, the previous temporary position remains available. When no temporary position exists, the original session center marker remains the fallback.

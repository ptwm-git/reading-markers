# Reading Markers 1.3.0

## 阅读体验升级

- 在现有浮动导航框中增加书签列表入口，不再另建一套独立侧栏。
- 列表支持当前文档 / 全部文档、内容摘要或文件名搜索、颜色筛选，以及跳转、改色和删除。
- 每篇 Markdown / PDF 文档自动保存一条续读记录；重新打开后，点击历史图标「继续上次阅读」。不会自动抢走当前视图位置。
- 永久书签、临时回退位置和上次阅读进度相互独立。翻查期间暂停覆盖进度，返回原处后恢复；也可以点击播放图标「从这里继续阅读」。
- Markdown 按屏幕上的阅读位置定位，不再依赖编辑光标；PDF 回退增加页内位置。
- 在 Obsidian 内改名或移动 PDF、Markdown 文件及其文件夹时，相关保存路径会跟随更新。
- 导航框保持拖拽、贴边、自动收起和低干扰样式；新增边界保护，避免按钮被窗口边缘遮住。

## English

Resume reading across restarts and browse markers from the existing floating navigation controls. The list supports current/all-document scopes, excerpt and file-path search, color filters, and marker management. Reading progress is protected during reference lookups. Markdown positions follow visible text, PDF returns retain page offsets, and stored paths follow renames and moves performed in Obsidian.

## Update Notes

- Update the existing plugin; reinstalling is unnecessary.
- Old floating panels left by 1.2.x are removed during the upgrade. Restart Obsidian once to also release any listeners left by those older versions.
- Manual installations replace only `main.js`, `manifest.json`, and `styles.css`. Keep `data.json`, which contains PDF markers and reading progress.
- Progress recording is on by default and can be disabled in plugin settings. The middle button remains a session-only return point.
- Supports desktop Obsidian 1.13.7+. Scanned PDFs still support page markers, but not text-level positioning or OCR.
- External file moves while Obsidian is closed, PDF page reordering, and cross-device merge conflicts are not automatically repaired.
- Marker notes, color meanings, export, HTML, and mobile support remain follow-up work.

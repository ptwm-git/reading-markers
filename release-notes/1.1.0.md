# Reading Markers 1.1.0

This release adds the first PDF support phase.

- Add page-level markers from a PDF page context menu or PDF toolbar action.
- Choose among six colors and group markers in the PDF marker bar.
- Click a page marker to jump back to that page.
- Change a PDF marker color or remove it from the marker context menu.
- Store PDF marker data separately from the PDF file.
- Show a notice for scanned image PDFs while keeping page-level markers available.

PDF text selection, PDF annotations, and HTML documents are outside this release scope. HTML support will be evaluated as a separate phase.
